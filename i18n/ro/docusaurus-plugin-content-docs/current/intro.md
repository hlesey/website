# Portofoliul de cursuri

Bine ai venit la programul nostru complet de cursuri Kubernetes.

## Cursurile noastre

Invata Kubernetes la cursurile noastre practice, sustinute de experti, gandite pentru profesionisti de orice nivel. Fiecare curs te pregateste pentru o certificare CNCF: vezi [traseele de certificare](/certifications).

### [Kubernetes Fundamentals - 2 zile](./kubernetes-fundamentals.md) 🚀

Primii pasi cu containere si Kubernetes: Docker, arhitectura si API-ul Kubernetes, Pods, Services, Deployments si persistenta.

**Certificare:** KCNA (Kubernetes and Cloud Native Associate)  
**Dificultate:** Incepator spre intermediar  
**Ideal pentru:** Dezvoltatori, ingineri de sisteme si arhitecti la inceput cu Kubernetes

### [Kubernetes for Platform Engineers - 3 zile](./kubernetes-for-platform-engineers.md) ⚙️

Kubernetes in productie: retelistica si Network Policies, workload-uri, RBAC, Helm, multitenancy, initializarea clusterului cu kubeadm, observabilitate, depanare si operarea clusterelor cu agenti AI.

**Certificare:** CKA (Certified Kubernetes Administrator), impreuna cu Kubernetes Fundamentals  
**Dificultate:** Intermediar spre avansat  
**Cerinte preliminare:** Kubernetes Fundamentals

### [Kubernetes for Developers - 3 zile](./kubernetes-for-developers.md) 💻

Construiesti si livrezi aplicatii pe Kubernetes: Pods, Services, Deployments, configurare, persistenta, RBAC, Helm, strategii de livrare, observabilitate, depanare si lucrul cu agenti AI.

**Certificare:** CKAD (Certified Kubernetes Application Developer)  
**Dificultate:** Incepator spre intermediar  
**Cerinte preliminare:** Experienta cu containere Linux (Docker)

### [Kubernetes Security - 3 zile](./kubernetes-security.md) 🛡️

Securizezi clustere si workload-uri: CIS Benchmarks, hardening pentru cluster si kernel, Pod Security Standards, securitatea lantului de aprovizionare, securitate la runtime, audit logging, admission control si securizarea agentilor AI.

**Certificare:** CKS (Certified Kubernetes Security Specialist), care necesita CKA  
**Dificultate:** Avansat  
**Cerinte preliminare:** Experienta practica cu Kubernetes (nivel CKA recomandat)

Cursurile Platform Engineers, Developers si Security se incheie cu o sesiune "Capture the Flag" de 2 ore, cu provocari Kubernetes reale, si includ o lectie despre lucrul cu agenti AI (Claude Code, OpenCode, AGENTS.md, skills) si limitele de care au nevoie pe un cluster.
