# SEO and AI-Assistant Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make qedzone.ro rank for Kubernetes + AI training searches and be quotable by AI assistants, in EN and RO.

**Architecture:** Docusaurus-native: config `headTags` for site-wide Organization JSON-LD, two small React components used from the course Markdown (Course JSON-LD, FAQ section + FAQPage JSON-LD from one data array), static `robots.txt`/`llms.txt`/social card, rewritten titles/descriptions/intros in EN and RO.

**Tech Stack:** Docusaurus 3.9.1, React 19, TypeScript, MDX.

**Spec:** `specs/2026-11-24-seo-design.md`

## Global Constraints

- Facts allowed: in-person in Bucharest; live online for Europe and the US; taught in Romanian and English; durations/certifications/AI topics as already on the site. Never state prices, exam vouchers, dates, other locations.
- Location sentence appears only in "Training Formats" (intro EN+RO), the course FAQs, and structured data.
- "Course Content" sections stay byte-identical; `scripts/check-i18n.sh` must keep passing.
- Romanian without diacritics.
- Course names stay English; the RO sidebar keeps showing the course name (`sidebar_label`).
- Commit with explicit paths.

## Review Focus

1. **Romanian course pages get English FAQ/schema** if the components aren't translated → Task 3 uses `<Translate>` for the FAQ heading and RO pages pass Romanian items; Task 4 check asserts `Intrebari frecvente` on `/ro/` course pages.
2. **Visible FAQ and FAQPage JSON-LD drift apart** → both rendered from the same `items` array (Task 3).
3. **Long titles truncated in Google** → titles ≤ 65 chars, descriptions 120–160 chars; Task 4 check enforces on course pages.
4. **Removing the blog breaks links** (`onBrokenLinks: 'throw'`) → build in Task 1 proves no link points to `/blog`.
5. **Invalid JSON-LD** (stray JSX, trailing commas) silently ignored by Google → Task 4 check parses every `application/ld+json` block with `JSON.parse`.
